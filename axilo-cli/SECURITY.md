# Security Policy

## Supported Versions

Only the latest version of Axilo CLI is supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability in Axilo CLI, please report it to security@example.com. Please do not report security vulnerabilities through public GitHub issues.

### When to Report a Vulnerability

- For potential security vulnerabilities in the code
- For sensitive security-related issues
- For potential security vulnerabilities in dependencies

### What to Include in Your Report

- A description of the vulnerability
- Steps to reproduce the issue
- The version of Axilo CLI you're using
- Any potential impact of the vulnerability

## Security Updates

Security updates will be released as patch versions. Please keep your installation up to date.

## Dependency Security

We use Dependabot to automatically update dependencies with known vulnerabilities. However, we still encourage users to report any security issues they find in our dependencies.
